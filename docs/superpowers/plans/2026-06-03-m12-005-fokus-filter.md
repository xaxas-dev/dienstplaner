# M12-005 Fokus-Filter Dienst-Phasen — Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Erweiterung des Plan-Grids um einen konfigurierbaren Multi-Select-Fokus-Filter: ShiftTypes erhalten ein `filter_group`-Textfeld; die ShiftTypeDragBar zeigt Gruppen-Chips; aktive Gruppen dimmen nicht zugehörige Zellen.

**Architecture:** `filter_group: str | None` als neues nullable Feld auf `ShiftType` (Migration + ORM + Schema). Frontend leitet Gruppen-Chips dynamisch aus ShiftType-Daten ab. State `activeFilterGroups: Set<string>` in `PlanPage` ersetzt `focusMode`. Prop-Kaskade: PlanPage → ShiftTypeDragBar + UnifiedPlanGrid → UnifiedShiftCell.

**Tech Stack:** Python 3.12 / Alembic / FastAPI / Pydantic v2 (Backend); React 18 / TypeScript / Vitest / Tailwind (Frontend)

- [ ] **D1: Props-Schnittstelle und Render ersetzen**

`ShiftTypeDragBar.tsx` vollständig ersetzen (Hilfsfunktionen `makeShiftTypeDragId`, `parseShiftTypeDragId`, `ShiftTypeChip` bleiben unverändert):

```tsx
interface ShiftTypeDragBarProps {
  shiftTypes: ShiftType[]
  activeFilterGroups: Set<string>
  onFilterGroupToggle: (group: string) => void
  onFilterGroupClear: () => void
}

export function ShiftTypeDragBar({
  shiftTypes,
  activeFilterGroups,
  onFilterGroupToggle,
  onFilterGroupClear,
}: ShiftTypeDragBarProps) {
  const groups = [
    ...new Set(
      shiftTypes
        .map((st) => st.filter_group)
        .filter((g): g is string => g != null),
    ),
  ].sort()

  return (
    <div
      className="flex flex-wrap gap-2 p-3 rounded-xl border border-line bg-card"
      aria-label="Dienst-Chips zum Ziehen"
    >
      <span className="text-[10px] font-medium text-muted-foreground uppercase tracking-wide self-center">
        Dienste
      </span>
      {shiftTypes.map((st) => (
        <ShiftTypeChip
          key={st.id}
          shiftType={st}
          dimmed={
            activeFilterGroups.size > 0 &&
            st.filter_group != null &&
            !activeFilterGroups.has(st.filter_group)
          }
        />
      ))}
      {groups.length > 0 && (
        <div className="ml-auto flex gap-1 self-center flex-wrap">
          <button
            onClick={onFilterGroupClear}
            className={[
              'px-3 py-1 rounded-lg text-xs font-medium border transition',
              activeFilterGroups.size === 0
                ? 'bg-accent text-white border-accent'
                : 'bg-paper text-ink-3 border-line hover:bg-paper/80',
            ].join(' ')}
          >
            Alle
          </button>
          {groups.map((group) => (
            <button
              key={group}
              onClick={() => onFilterGroupToggle(group)}
              className={[
                'px-3 py-1 rounded-lg text-xs font-medium border transition',
                activeFilterGroups.has(group)
                  ? 'bg-accent text-white border-accent'
                  : 'bg-paper text-ink-3 border-line hover:bg-paper/80',
              ].join(' ')}
            >
              {group}
            </button>
          ))}
        </div>
      )}
    </div>
  )
}
```
